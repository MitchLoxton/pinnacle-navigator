# HK60 V2 — FROZEN ~60-BET HONG KONG CANDIDATE

Freeze date: 2026-09-14.

Status: **FROZEN RESEARCH / CONTROLLED FORWARD-TRIAL CANDIDATE. NOT PRODUCTION-APPROVED.**

This rule was chosen using completed 2015-2025 HKJC R3 source rows only. The 2026 source-cutoff rows are reserved for a post-freeze diagnostic and were not used to select this V2 rule. Because 2026 has already occurred before this freeze, that diagnostic is not genuinely prospective evidence. Genuine forward evidence starts after this freeze.

## Objective
Target approximately 60 bets/year with one horse per race, no rebate dependence, positive calibrated model expectation, strong historical return, materially controlled chronological drawdown, and simple round rules rather than a fine-tuned lookup table.

Historical research scale: fixed A$5,000 per selection solely for apples-to-apples risk/dollar metrics. This is **not** an instruction to stake A$5,000 live before execution/capacity/forward gates pass.

## Frozen HK60 V2 rule
Historical/live scoring convention: WIN only; no rebate; damage only the winning profit portion of price by 3%; calibrated probability uses the frozen R3 log-odds calibration intercept 0.1679327961221175.

A runner enters the qualifying pool only when stressed calibrated model EV at the 3% price-damage convention is >= 0 and either condition A or B is true:

### A. R2 CORE sleeve
- R2 core = true;
- market rank <= 8;
- research/executable WIN odds **5.00 to <8.00** OR **18.00 to <30.00**.

### B. Satellite-only sleeve
- satellite-only = true; and either:
  - WIN odds **3.00 to <8.00** with market rank <= 4; OR
  - original raw model EV >= **+12.0%**.

### One-bet-per-race rule
If multiple runners qualify in the same race, select **one horse only**:
1. highest stressed calibrated model EV;
2. tie-break by lower WIN odds;
3. then higher original raw model EV.

No Kelly. No martingale. No same-race multiple selections. No threshold changes after seeing 2026 or future outcomes while retaining the HK60 V2 name.

## Promotion gates
HK60 V2 is not to be called production-ready from completed history alone. Promotion requires all of:

1. Post-freeze selections logged before results with no threshold changes.
2. Real executable HKJC/bookmaker WIN quotes timestamped before bet decision.
3. Accepted/fillable stake and price evidence showing slippage does not destroy model EV.
4. Forward calibration remains materially positive and not grossly inconsistent with the frozen probability model.
5. Forward drawdown remains inside a predeclared bankroll/risk envelope.
6. No operational reliance on rebate, synthetic prices, hidden discretionary horse choice, account evasion or martingale.

Until those pass: shadow / paper / tiny controlled validation only.
