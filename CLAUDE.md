# Claude project instructions

Before working on the racing app, read `racing/AI_CONTEXT.md` completely.

Treat it as the master project handoff. Then inspect the current canonical files and Supabase evidence before making claims or edits.

Key rules:
- Do not invent missing racing evidence.
- BET_LOCKED / sent BET_NOW signals are immutable system bets.
- Personal placement is separate from system statistics.
- Do not alter frozen predictive rules without explicit permission.
- Keep credentials out of source control and chat.
- Validate changes before committing.
- Prefer a branch and pull request for material changes.
